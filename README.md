# Rock Paper Scissors Game 

This is a simple and responsive Rock Paper Scissors game made using HTML, CSS and JavaScript.

The user can choose between rock, paper and scissors while the computer randomly selects its choice. The game then displays the winner and updates the score.

## Features

- Responsive design for mobile, tablet and desktop
- Interactive UI with animations
- Score tracking
- Rules modal popup
- Random AI choice generation
- Winner highlight effect
- Play again functionality

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone the repository
2. Open the project folder
3. Run `index.html` in browser
